# Поиск продукта для обычных криптопользователей: 20 сентября

## Уточнения пользователя

- Обычный агент с доступом к данным может выполнить анализ из ONE RULE; убедительное преимущество отдельного продукта пока не показано.
- Наблюдение за поведением одного адреса обрывается при смене адреса. Метка Smart Money не гарантирует пользу для следующего за ним человека.
- ALERT LAB воспринимается как ещё один сервис уведомлений. CoinMarketCap действительно предлагает price alerts и AI Alerts; наличие там идентичной исторической проверки ончейн-условий не установлено. [CMC, описание возможностей](https://coinmarketcap.com/academy/article/coinmarketcap-features-track-research-and-build-with-crypto-data).
- Искать для обычных криптопользователей и трейдеров; продукты для команд и разработчиков не являются приоритетом.

## Что проверено дополнительно

Защита кошельков AI-агентов уже представлена Coinbase, MetaMask, OnlyFence, Cabal и другими. В частности, Cabal описывает ограничения ликвидности, размеров сделок и потока сигналов. Это делает общий «ремень безопасности для агента» слабым заявлением об оригинальности. [Coinbase](https://www.coinbase.com/developer-platform/products/agentic-wallets), [MetaMask](https://metamask.io/agent-wallet), [OnlyFence](https://github.com/seallabs/onlyfence), [Cabal](https://cabal.trading/docs/agentic-guardrails).

Проверка публичных прогнозов также занята: OnlyKOLs, CallScore, SCHROD и Notch описывают учёт результатов или неизменяемые записи прогнозов. Их заявления не проверены аудитом реализации. [OnlyKOLs](https://onlykols.io/), [CallScore](https://call-score.com/about), [SCHROD](https://schrod.io/), [Notch](https://www.notch.finance/).

Наличие аналога не запрещает участие в конкурсе. Но одно переименование известной функции не обосновывает сильную конкурсную заявку.

## Новый кандидат A: ордер с условиями отмены

**Пользовательская ситуация:** человек поставил покупку на более низкой цене, основываясь на определённой картине владения токеном. Пока ордер ждал, картина изменилась. Цена достигает уровня входа, но первоначальные основания уже не выполняются.

**Предлагаемый продукт:** при создании покупки сохранить одно-два точных ончейн-условия и условия окончательной отмены. Nansen обновляет наблюдения; приложение решает, продолжать ожидание, отменить поручение или разрешить исполнение. Цена отвечает за момент покупки, ончейн-условия - за её допустимость в рамках поручения пользователя.

**Иллюстративный пример, не инвестиционная рекомендация:** пользователь выбирает цену, сумму и фиксированную группу адресов. Если суммарный остаток токена на этих адресах уменьшился более чем на заданную долю, поручение отменяется. Перевод на новый адрес тоже уменьшает наблюдаемый остаток: приложение не объявляет перевод продажей и не делает вывода о личности владельца. Условия должны ясно объяснять такую консервативную отмену.

Возможен другой шаблон на основе агрегированных потоков. Его смысл, период измерения и доступность данных нужно подтвердить отдельно; нельзя обещать фильтр от всех манипуляций или определение «настоящей умности» держателей.

**Демо:** два поручения с одинаковой ценой; для одного условия продолжают выполняться, для другого данные вызывают отмену. Лента объясняет каждое состояние и показывает источник. Демонстрационная история отмечена как воспроизведение, исполненный реальный ордер подтверждён транзакцией.

**Техническая осуществимость:** Nansen имеет holders API и quote/prepare для обменов на Solana и Base. Это не готовый API условных ордеров: проверку условий, отмену, хранение состояния и безопасное исполнение потребуется реализовать. [Holders](https://docs.nansen.ai/api/token-god-mode/holders), [Quote](https://docs.nansen.ai/api/trade/spot-trading/quote).

**Критические границы:** свежесть данных; повторная проверка перед подписью; срок годности котировки; однократное исполнение; отсутствие автоматического допуска при недоступности данных; ограниченные полномочия исполняющего сервиса. Между проверкой и исполнением состояние может измениться - точную защиту на уровне блока Nansen API не обещает. Премиальные метки holders API по текущей документации требуют платного плана и стоят 150 кредитов за вызов; они не должны включаться незаметно.

**Конкуренция:** Coinrule уже даёт комбинации условий и исполнение, а Nansen CLI - ценовые лимитные ордера на Solana. Предлагаемое отличие - конкретный сценарий отмены устаревшего торгового поручения по ончейн-условиям с ясным объяснением. Проверка рынка не доказывает, что это первый такой продукт. [Coinrule](https://help.coinrule.com/articles/497089-build-your-condition-block), [Nansen CLI](https://github.com/nansen-ai/nansen-cli).

**Оценка:** сильнее отвечает требованию «данные управляют логикой», чем предыдущие аналитические варианты. Оригинальность и востребованность ещё не доказаны. Первая версия: одна сеть, один тип покупки, один-два шаблона условий, без общего AI-конструктора.

## Новый кандидат B: забрать заданную сумму из нескольких токенов

**Поручение:** получить заданную сумму USDC, сохранив перечисленные пользователем активы и не превысив предел издержек.

**Логика:** Nansen предоставляет поддерживаемые остатки и котировки. Приложение выбирает допустимые объёмы продажи с учётом ограничений и готовит исполнение. Разница между оценкой портфеля и котировкой продажи становится видна до подтверждения. Отсутствие маршрута - отдельный результат, не нулевая цена.

**Польза:** человеку не нужно вручную подбирать, какие доли нескольких позиций продавать для получения нужной суммы.

**Ограничения:** котировки нескольких сделок не являются гарантией общей выручки; они могут конкурировать за одну ликвидность. Нужны повторная оценка после исполнения, обработка частичного результата и явные лимиты. Первую версию ограничить спотовыми токенами одной сети. Вывод в USDC не означает вывод на банковский счёт.

**Найден близкий аналог:** Equicaelum описывает выбор требуемой суммы, стратегии продажи и подтверждение исполнения; сайт находится в раннем доступе. Vexidus документирует команды liquidate/cash out с исключениями активов. Поэтому сценарий полезен, но не выбран как убедительный конкурсный фаворит. [Equicaelum](https://equicaelum.finance/), [Vexidus](https://docs.vexidus.io/developers/intentvm-guide/).
