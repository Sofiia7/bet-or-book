Record the final deployed site. Use actual returned dates, figures and verdicts. Keep operator credentials out of the recording.

| Time | Action | Spoken point |
| --- | --- | --- |
| 0:00-0:15 | Landing page; paste wallet/link | A whale's short alone does not prove a bearish view. |
| 0:15-0:45 | One live check and guess mechanic | Positions, holdings and activity are checked; missing sources stay visible. |

| 1:35-1:55 | Another saved example | Same-address hedge differs from inventory. Saved readings open for free. |
| 1:55-2:15 | Full analysis | Show the rule and open question. If a source fails, acknowledge it and retry once. |
| 2:15-2:40 | Explore, watchlist, sharing, PNG | Older rules are labelled. Watchlists stay in this browser. Links preserve the reading. |
| 2:40-2:55 | Repository and closing | Hyperliquid intelligence, with Nansen for cross-dex positions, cross-chain balances and funding links. |

Never splice a saved result into a live request. If a provider fails, show the limitation honestly and record a complete live check when it becomes available.
