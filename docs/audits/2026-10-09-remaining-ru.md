## Дополнительный пакет v9

По просьбе пользователя реализован следующий пакет. Партнёра пилота нет; канал Telegram/email не выбран. Описание подключения и ограничений: [publisher-pilot.md](../publisher-pilot.md).

- Meaningful-change alerts реализованы как in-app pilot: четыре разных вопроса глобально, примерно раз в четыре часа, 72 часа, максимум один cron job в час. Защита от повторов, атомарная ёмкость/lease, browser capability token, Stop. Неполный/несохранённый результат не заменяет baseline; бюджет может приостановить цикл. Уведомления доступны в открытом приложении. Telegram/email/Web Push не подключены.
- Claim checker реализован: четыре ограниченных утверждения, оценка по датированным данным без LLM и новых платных вызовов. Выбор передаётся в ссылке и publisher API/widget.
- Publisher widget и read-only API реализованы; Copy embed доступен в Share. Bot adapter печатает готовый текст, но не отправляет его. Платный API и коммерческие права не объявлены.
- Обучающие сохранённые кейсы: вопрос → доказательства. Совпадение с эвристикой не выдавать за знание настоящей стратегии владельца.
- Opposing legs считаются для выбранного актива (long/short/net), а не по нерелевантной паре в портфеле. Существующие неопределённости выбранного актива сохраняют Unknown; spot + встречные контракты не объявлены доказанным безопасным hedge.
- HIP-3 live venue/deployer/oracle-updater provenance реализован с отдельным состоянием недоступного реестра. Реестр не доказывает underlying: ограниченная модель идентичности актива пока сохраняется. Полная верификация oracle definitions остаётся открытой, не заменена угадыванием по тикеру.
- Book diagnostics реализованы: расстояние от свежего L2 mid либо явно обозначенного mark, отдельные наблюдения котировок. Best-effort KV samples не доказывают непрерывность. Инструмент оценки независимой разметки готов; разметка пуста, precision/recall не измерены. Grade не вероятность.
- Lazy PnL/funding-age реализованы: основной UI использует core; дополнительный контекст загружается отдельно. Source positions переиспользуются до минуты при смене asset, исходный source timestamp сохраняется. Core использует поэтапный атомарный reserve с повторами/страницами; полный context сохраняет максимальный резерв. Проверены конкурентные запросы и учёт расходов в workerd. Другие source observations заново читаются для выбранного вопроса.
- Frontend выделяет transport и monitor modules и использует общие TypeScript claim/share/saved-reading модели. Publisher DTO versioned. Полное разбиение canvas/Explore остаётся отдельным рефакторингом; framework не менялся.
- Ценообразование, права на embedding, SLA и коммерческие ключи — после проверки покупателя, не из гипотетического спроса.

## Сохранить и не расширять сейчас

Сохраняются observe/interpret/present, versioned observations, атомарный spend ledger, POST для платных проверок, бесплатные сохранённые ссылки, границы ownership, workerd/CI и небольшой frontend без framework.

«Don't Get Rekt Copytrading» исключён из изменений по прямому указанию пользователя. Execution, wallet connect, токен/баллы, referrals, PnL-лидерборд, общий AI-чат, социальная лента, новые сети, массовые scans, полная ownership attribution и derivatives risk engine не входят в рекомендации для этого спринта.
