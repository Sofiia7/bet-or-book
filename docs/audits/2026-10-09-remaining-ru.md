## Рекомендации, которые ещё НЕ реализованы

Эти пункты были отложены по приоритетам исходного аудита. «Все основные исправления спринта сделаны» не означает, что сделаны все перечисленные механики. Отдельного запрета пользователя на них нет; ниже полный открытый технический backlog, без заявления о готовности.

- Meaningful-change alerts: размер, сторона, покрытие, полнота и причины; бюджет, дедупликация, ручное обновление отдельно.
- Claim checker: выбранный актив и утверждение из alert. Поле без LLM возможно, но сначала закончить основной путь alert → evidence → share.
- Publisher widget/bot и платный API: только с реальными авторами/пилотом, проверенными правами на данные и стоимостью ответа.
- Обучающие сохранённые кейсы: вопрос → доказательства. Совпадение с эвристикой не выдавать за знание настоящей стратегии владельца.
- Релевантные opposing legs для выбранного актива; нынешний консервативный guard сохраняется до корректного расчёта.
- HIP-3 registry venue/deployer/oracle вместо ограниченной whitelist-модели.
- Book: persistence котировок, расстояние от mid, калибровка на размеченных наблюдениях. Grade не вероятность.
- Снижение цены: lazy optional reads, переиспользование observation при выборе asset, поэтапный reserve; проверить отмены/повторы и учёт расходов.
- Разделение большого frontend на модули и общие DTO без смены framework перед конкурсом.
- Ценообразование, права на embedding, SLA и коммерческие ключи — после проверки покупателя, не из гипотетического спроса.

## Сохранить и не расширять сейчас

Сохраняются observe/interpret/present, versioned observations, атомарный spend ledger, POST для платных проверок, бесплатные сохранённые ссылки, границы ownership, workerd/CI и небольшой frontend без framework.

«Don't Get Rekt Copytrading» исключён из изменений по прямому указанию пользователя. Execution, wallet connect, токен/баллы, referrals, PnL-лидерборд, общий AI-чат, социальная лента, новые сети, массовые scans, полная ownership attribution и derivatives risk engine не входят в рекомендации для этого спринта.
