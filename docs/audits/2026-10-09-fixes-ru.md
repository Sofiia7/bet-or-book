## Дополнительные изменения

- Позиции, отстоящие от оригинального check на 15 минут и более, либо имеющие timestamp более чем на минуту в будущем, не смешиваются с holdings/orders как согласованное измерение. Это Unknown с отдельной причиной и dataQuality; повторное открытие вчерашнего согласованного snapshot не делает его ошибочным.
- Кэш main dex не объявляет позицию отсутствующей на всех площадках. Для бесплатного вывода об отсутствии нужны полный roster и полное venue coverage. Старые укороченные списки остаются поддержаны.
- Карточка: предмет чтения и адрес → дата/возраст → вывод → два факта → Share/Save → компактные leverage/liquidation → открытый вопрос → диаграмма → полный анализ. Повторная форма скрыта до Check another. Подробные vitals и сравнение остаются в Full analysis.
- «Hedged» в пользовательском интерфейсе — «Spot-covered short». Book headline описывает evidence; grade не выдаётся за вероятность. Long показывает неприменимость spot coverage вместо 0%.
- У диаграммы есть долларовые суммы и пояснение, что это иллюстрация покрытия, не граф транзакций. Собственные holdings и funders явно различаются.
- Saved positions хранят asset, side, snapshot и дату. Open saved бесплатен; Refresh запускается вручную. Старые массивы адресов читаются без потери списка. Нет обещания автоматического мониторинга.
- Доступны все прочитанные позиции: первые пять и поиск по полному списку. Старый неполный roster не доказывает отсутствие шестой позиции.
- Boards используют текущие сопоставимые чтения. Покрытые shorts сортируются по близости к размеру short; это не рейтинг безопасности. Пустой современный Book board не подменяется историей.
- У основных чтений есть клиентский timeout: 15 секунд для saved/compare/gallery, 55 секунд для live. Timeout не отменяет серверный учёт уже потраченных кредитов; повторный POST автоматически не отправляется.
- При недоступном бюджете/провайдере видна ограниченность самого чтения и путь к бесплатным примерам. Не предлагается бесполезный немедленный retry при выключенных кредитах.
- Pitch/demo согласованы с реальными тремя контрастами. Четвёртый пример показывает предел maker flow, а не несуществующий текущий Book. Team/location требуют собственных данных основателя.
- Три главных примера получили вопросы перед открытием; четвёртый находится в More evidence cases. Карточка даёт evidence takeaway, а Unknown для funders/partial spot/overcoverage показывает подходящие суммы и границу вывода.
- Несколько адресов в alert требуют выбора до POST; дубликаты адреса объединены. Добавлена подсказка о wallet link и отсутствии парсинга X URL.
- После 8 секунд ожидания доступен бесплатный пример. Поздний ответ не заменяет выбранный reading. Budget-off warning и recovery проверены на изолированных фикстурах без платных запросов.
- Saved positions получили имена; новое сохранённое live reading обновляет дату/ссылку той же позиции и сохраняет имя. Более старая дата не перезаписывает более новую.
- Explore начинается с Recent case studies; сравнение, полный список и архив открываются отдельно. Повторный provider lead убран с первого уровня карточки; для funder-кейса рядом показано собственное spot-покрытие.
- Save стоит рядом с Share. Подтверждение объясняет хранение в этом браузере, даёт имя позиции, копирование saved link и переход к списку. Copy reading переносит факты, исходную дату, открытый вопрос, attribution и ссылку; X draft сохраняет дату и ограничение при сокращении headline. Неуспешно сохранённый snapshot не получает выдуманную ссылку.
- После ручного обновления saved position сохраняется предыдущий пользовательский snapshot. Сравнение вынесено из Full analysis, даёт бесплатную ссылку назад, явно описывает отсутствие material changes или недоступность сравнения. Переключение вопроса не показывается как изменение сделки; старый/несохранённый ответ не сдвигает baseline. Это ручное сравнение, не alerts.

## Что остаётся перед подачей

1. Публикация кода/OG и production smoke выполнены. Перед записью видео повторить доступность; прежние примеры не выдавать за новые live checks.
2. Edge rate-limit из [cloudflare-edge-protection.md](../cloudflare-edge-protection.md): подготовлен, не применён; Wrangler OAuth не даёт WAF write. Нужен доступ к зоне через аккаунт владельца.
3. Остаток измерен: 858 на 9 октября 06:49:20 UTC. Контролировать его к judging. Cap 80 / demo reserve 40 / floor 100 не увеличены. В v9 core резервирует по платным этапам; полный context сохраняет максимальный reservation 18. Число доступных проверок зависит от фактических ответов и повторов; saved reads бесплатны.
4. Реальные пользовательские сессии по [user-validation-2026-10.md](../user-validation-2026-10.md). Обратная связь, repeat use, paying users и партнёрства не придуманы.
5. Запись финального видео, подтверждение командных данных, disclosure и подача заявки владельцем; сохранить подтверждение.
6. Анонимная воронка example/check → reading → share/save → repeat опубликована в существующие Worker logs; [описание и ограничения](../product-metrics.md). Собственные production smoke-события 9 октября не считать активацией. Исторических данных и уникальных пользователей из этих событий получить нельзя; actual demand остаётся задачей исследования.

По дальнейшему указанию пользователя технический пилот alerts/widget/read-only API добавлен в v9. Коммерческий API и внешняя доставка ботом не подключены. Execution, wallet connect, token, referrals, новые сети и LLM chat не добавлены.
